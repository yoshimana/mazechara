# まぜキャラ (MazeChara)

二次元キャラクターを現実の写真へ自然に溶け込ませる、ブラウザ完結型の画像合成・ライティングWebツールです。

🔗 **Web公開URL**: [https://4407.jp/app/mazechara/](https://4407.jp/app/mazechara/)

---

## 概要

イラストや立ち絵（透過PNG/WebP）を風景や日常の写真に重ねる際、不自然に浮いて見えてしまう最大の要因は「光」「影」「奥行き」の不一致です。

「まぜキャラ」は、光源の向き、接地影、落ち影の遠近感、環境光の回り込み（ライトラップ）、リムライト、色温度、そして手前物体による遮蔽（オクルージョン）までをリアルタイムに調整・合成し、まるでキャラクターがその場に立っているかのような一枚を誰でも手軽に作成できます。

画像処理はすべてお使いの端末（ブラウザローカル）で完結するため、**写真やイラストが外部サーバーへアップロードされることは一切ありません。**

---

## 主な機能

- **背景からの自動マッチ**: 背景写真のピクセル明暗分布やカラーバランスを自動解析し、影の向き・濃さ・色温度・露出をワンタップで自動最適化。
- **クイックプリセット**: 標準、晴天、くもり、夕暮れ、夜間、ドラマチックなど、シーンに応じたワンタッチ切り替え。
- **リアルタイム接地影 & 落ち影**:
  - 足元を地面に密着させる自然なコンタクトシャドウ。
  - 角度・長さ・遠近パース・ぼかし・地面の凹凸（波打ち）を細かく調整できるドロップシャドウ。
- **ライトラップ (光の回り込み)**: 背景写真の強い光がキャラクターのエッジへシルキーに回り込むプロ仕様のコンポジット表現。
- **リムライト (輪郭ハイライト)**: 逆光・半逆光シーンでキャラクターの輪郭を照らすエッジライト。背景からのスポイト色抽出にも対応。
- **手前物体による前景遮蔽 (オクルージョン)**: 写真の手前にある柱・机・手すりなどを大まかになぞるだけで、輪郭に自動吸着してキャラクターやその影を物体の背後へ自然に回り込ませる奥行き表現。手前物体からキャラへの影落ちにも対応。
- **被写界深度 (背景ボケ)**: 背景のピント位置とボケ感を調整し、一眼レフで撮影したかのような立体感を演出。
- **フィルムグレイン & ビネット**: 写真とイラストのテクスチャ粒子感を統一するグレインノイズや周辺光量落ち。
- **トリミング & 回転微調整**: 読み込み時の水平・垂直スナップ付き回転調整やゴミ除去機能。
- **PWA & 多言語対応**: 日本語・英語に完全対応。スマホのホーム画面に追加してアプリ感覚で利用可能。

## 使い方

1. **背景写真をアップロード**: 風景や部屋などの写真を読み込みます。
2. **キャラクターをアップロード**: 背景が透過された立ち絵やイラスト（PNG/WebP）を読み込みます。
3. **位置とサイズを調整**: プレビュー上でドラッグして配置し、ピンチやスライダーで大きさを合わせます。
4. **「自動マッチ」またはプリセットを選択**: 背景光に合わせた初期調整が一瞬で適用されます。
5. **詳細設定でこだわりをプラス**: 影の角度、ライトラップ、手前遮蔽などをスライダーで直感的に調整。
6. **保存 / 共有**: 「画像を保存／共有」ボタンで高画質な仕上がり画像をダウンロードまたはSNS共有できます。
